# Architecture Map — GlobalSizeChart.com

## Site model

Static HTML site (~1,172 HTML files) with client-side conversion in `app.js`, backed by JSON datasets. Pages are authored directly and/or generated by Node scripts (Cheerio). Deployment targets Cloudflare (cache rules documented); local dev via `python3 -m http.server`.

```
data/*.json ──┬──► app.js (runtime converter)
              │
config/*.json ┤
              │
programmatic/templates/*.html ──┐
scripts/generate-programmatic-pages.js ──┼──► programmatic-pages/ (765)
scripts/generate-all-pages.js ───────────┤
scripts/generate-pages.js ───────────────┤
scripts/inject-aeo-layer.js ─────────────┼──► AEO blocks on existing HTML
scripts/ai-answer-injector.js ───────────┘
scripts/migrate-hero-tool.js ─────────────► hero-tool layout (batch HTML edit)
scripts/standardize-footer.js ────────────► footer sync from master-footer.html
scripts/generate-sitemaps.js ─────────────► sitemap.xml + sitemaps/*
```

## Sources of truth

| Concern | Source of truth | Notes |
|---------|-----------------|-------|
| **Pages (programmatic shoe conversions)** | `scripts/generate-programmatic-pages.js` + `programmatic/templates/` + `data/programmatic_routes.json` | Output: `programmatic-pages/` |
| **Pages (clothing conversions)** | Same generator + `clothing/` output dir | 126 HTML files |
| **Pages (measurement)** | Generator + `measurement/` | 120 HTML files |
| **Pages (manual/editorial)** | Root-level `*.html`, `brands/`, `semantic/`, `legal/`, hubs | Mixed hand-edited + injectors |
| **Navigation (header)** | Per-page inline `<nav class="primary-nav">` | **Not centralized** — homepage vs inner pages differ |
| **Navigation (footer)** | `scripts/lib/master-footer.html` | Enforced by `standardize-footer.js` |
| **Converter data (shoes)** | `data/shoe_sizes.json` | Regions in rows: us, uk, eu, jp, cn, cm |
| **Converter data (clothing)** | `data/clothing_sizes.json` | men/women/kids × tops/pants/dresses |
| **Converter logic** | `app.js` | Loaded on converter pages; builds `sizeDatabase` at init |
| **Schema (programmatic)** | Inline in generated HTML + helpers in `generate-programmatic-pages.js` | Heavy multi-type JSON-LD per page |
| **Schema (authority org)** | `scripts/inject-authority-org-schema.js` | Injects `data-authority-org-global="1"` block |
| **AEO content blocks** | `scripts/programmatic-structural-modules.js`, `scripts/inject-aeo-layer.js`, `scripts/ai-answer-injector.js` | why-vary, FAQ, quick answer |
| **Quick Converters snippet** | `scripts/lib/quick-converters-snippet.js` | Embedded in ~779 pages — **broken hrefs** (see issues) |
| **Sitemaps** | `sitemap.xml` → `sitemaps/sitemap-{high,medium,low}.xml` + `indexing-feed.xml` | Generated by `generate-sitemaps.js` |
| **robots.txt** | Root `robots.txt` | Allows major bots; points to sitemap |
| **Styles** | `styles.css` | Global; hero-tool, card-grid, converter UI |
| **Ads layout** | `styles.css` + HTML ad-slot placeholders | No live AdSense script in repo |

## Page-generation pipeline

1. **Data** — `data/shoe_sizes.json`, `clothing_sizes.json`, `programmatic_routes.json`, brand configs  
2. **Generate** — `node scripts/generate-programmatic-pages.js` (primary bulk generator)  
3. **Orchestrate** — `scripts/generate-all-pages.js` coordinates multiple generators  
4. **Post-process injectors** (mutating; not run in this audit):
   - `inject-aeo-layer.js` — AEO sections
   - `ai-answer-injector.js` — AI FAQ / quick answer blocks
   - `internal-link-injector.js` — crawl/sitemap link injection
   - `inject-noindex-longtail.js` — noindex on longtail kids CM pages
   - `migrate-hero-tool.js` — hero-tool layout migration
   - `standardize-footer.js` — footer replacement
5. **Validate** (read-only capable):
   - `prebuild-link-validation.js`
   - `footer:check` (`standardize-footer.js --check`)
   - `content-quality-audit.js`
   - `adsense-policy-checker.js`
   - `breadcrumb-audit.js`, `phase1275-structure-audit.js`, `adsense-layout-validator.js`

## Deployment structure

- **Static files** served from repo root (no Next.js/React app shell)
- **Cloudflare** — `cloudflare/cache-rules.md`, `cloudflare/BOT-AND-SECURITY.md`
- **Build scripts** — `npm run build:cf` (cache headers + asset optimize); no `wrangler.json` in repo
- **Dev server** — `npm run dev` → port 5190

## Shared components

- `components/` — 20 HTML partial-like files (reference patterns)
- `programmatic/templates/conversion-template.html`, `region-template.html`, `category-template.html`
- `scripts/programmatic-structural-modules.js` — reusable HTML module strings
